# Haunted Landlord - project notes for Claude

**Standing rule: update this file after every change to the project** (new features, tuning, file moves, bugs found/fixed, decisions). Keep the Changelog current and edit the other sections if they become stale.

## What this is
Browser idle game, design in `haunted_landlord_plan_v2.pdf` (pitch: "Your tenants are dead, your rent is not."). Tone: funny-spooky, dry landlord humor, never gory. The game is plain HTML/CSS/JS in `game/` (deployable to the web as-is). `main.js` is an Electron shell used only for desktop testing.

## Commands
- `npm start` - launch the Electron test app (loads `game/index.html?dev=1`, the homepage)
- `npm run sim` - pacing bot (`node tools/sim.js [clicksPerSec]`)
- `node tools/simsim.js [days]` - Simulator Mode smoke test / cash curve
- `node tools/tiers.js [clicksPerSec] [hours]` - first-purchase time of each tenant for a never-exorcising bot (tier pacing)
- Browser testing: `.claude/launch.json` has a `game-web` static server (python http.server, port 8123, serves `game/`). Open `http://localhost:8123/index.html?dev=1` (homepage) or `idle.html?dev=1` (Idle game directly). file:// URLs don't work in the preview pane.
- Syntax check: `node --check game/<file>.js`

## Hosting
- Live at https://jacobbpr2012.github.io/haunted-landlord/ (GitHub Pages, public repo `jacobbpr2012/haunted-landlord`). `.github/workflows/pages.yml` publishes `game/` on every push to `main`, so deploy = `git push`. `CONST.SHARE_URL` points there; swap it when a custom domain or Cloudflare Pages is set up (Pages needs a public repo on a free account). `gh` lives at `C:\Program Files\GitHub CLI` (add to PATH in new shells). Repo-local git identity is set (not global).

## Layout
- `game/data.js` - content and tuning constants (ghosts, rooms, upgrades, essence shop, achievements, jokes). `CONST.ESS_DIV` controls prestige pacing.
- `game/codex.js` - extends `HLData`: 58 Codex lodger ghosts in 9 families, seasons, cosmetics (theme/door/decor/pet), rival landlords, Chad constants. Loaded right after data.js (engine requires it in Node).
- `game/engine.js` - all rules and saves, no DOM; `Game` class; also runs in Node. Exposes `HLEngine`.
- `game/ui.js` - all rendering/input; `window.HL = {g, fmt}` for DevTools.
- `game/shared.js` - cross-mode Codex bridge (`HLShared`, localStorage key `haunted_landlord_shared`): Idle writes its discovered-ghost count, Simulator writes solved special guests. Loaded by idle.html and sim.html.
- `game/theme.css` + `game/theme.js` - 10 hotel front desk themes (Midnight concierge is the default). `theme.css` holds all colour/font/radius CSS variables per `[data-theme]` plus the front desk layer (sign plaque header, wooden `.counter` strip with `.bell-ic`, key rack, ledger tabs). `theme.js` (loaded in <head>) applies the saved theme (localStorage `haunted_landlord_theme`) and exposes `HLTheme.selectHtml()`; pickers live in Idle Settings, Simulator Settings tab and the homepage footer. Load order in each page: style.css, (sim.css / home.css), theme.css. style.css/sim.css/home.css must use `var(--...)` for colours, never new hard-coded hexes, or light themes (pastel, bnb) break.
- `game/audio.js` - WebAudio synth (no audio files). `game/share.js` - share-card canvas, copy/save.
- `game/index.html` + `home.css` + `home.js` - homepage with game mode selection (Idle playable, Simulator is a "coming soon" card; passes ?dev/season params to idle.html, shows Continue if a save exists). `game/idle.html`, `game/style.css` - the Idle game markup and styles. CSP is strict: scripts from `self` only, no inline scripts.
- `tools/sim.js` - balance bot; `tools/tiers.js` - tier pacing bot.
- Simulator Mode: `game/sim.html`, `game/sim.css`, `game/sim/data.js` (8 rooms, 10 guests, 22 complaints, 8 daily events, 3 stories, 6 upgrades, staff, tuning in `SimData.CONST`), `game/sim/engine.js` (`SimEngine.Sim`, no DOM, day phases plan/shift/summary, save key `haunted_landlord_sim_save`), `game/sim/ui.js` (re-renders on each click, turn-based). `node tools/simsim.js [days]` is the bot smoke test.

## Conventions and gotchas
- Scripts are plain globals (`HLData`, `HLEngine`, `HLSound`, `HLShare`, `HLFormat`), loaded in order by idle.html.
- Engine -> UI communication is `g.onEmit(type, data)`; types: buy, toast, event, eventEnd, ach, cellar, mabel, gary, exorcism, seance, season, house, week.
- Test URL params: `?dev=1` (test tools in Settings), `?season=winter|valentine|spring|summer|halloween` forces a season. Dev tools also have 'Cycle season' and 'End race week'.
- Save shape grew additively (codex, house, week, visits, tutorial, settings.notify, more stats) and `adopt()` fills defaults, so `v` is still 1. Saves without `tutorial` skip it if the player already clicked.
- Event objects in the engine now carry `title`, `text`, `labels` (UI reads those, not `def`), so events can be dynamic (seasonal visitors).
- UI updates buttons in place (tenants/upgrades) rather than rebuilding every tick, so clicks aren't lost. Only rebuild via the `dirty` flags.
- Save key `haunted_landlord_save`, versioned (`v: 1`); export codes start `HL1:`. Bump `v` and add migration if the state shape changes.
- Escape any user text (house name) with `esc()` before putting it in innerHTML.
- Python tool calls: don't use `python -I` for pip-installed packages (user site is ignored).

## Current tuning (as of last change)
- Tenant price growth 1.15; offline rate 60% (+10% per Accountant), cap 8h; Essence = floor(sqrt(run / 5e9)), +10% rent per Essence earned up to 100 Essence, then sqrt growth (added so the new late tiers can't snowball).
- New tenants (cost/base/growth): Karen 6e8/2.4e6/1.19 (Ballroom 3e8), HOA 3e11/1e9/1.22, Chad 2e15/4e12/1.25 (Tower 5e14), Dolores 1e20/1e17/1.28, Landlord's Landlord 1e25/1e22/1.32 x1.05 all rent each (Penthouse 1e24). Ghosts can set their own `growth` (engine `growth(id)`). Seance cost 500 x 1.22^found. Lodgers give +0.25/0.5/1/1.5% rent (set bonus +3%, holiday +5%). Seasons x1.1 rent (Halloween x1.15).
- Bot sim (`npm run sim`, and `node tools/tiers.js [cps] [hours]` for first-purchase times, never exorcises): first Exorcism ~15 min, expect ~1h for humans. Bot first buys: Karen 26m, HOA 36m, Chad ~2h, Dolores ~5h, Landlord ~12h. Tiers are gated by cost vs how far the cheapest-first bot has climbed the old tiers; wealth grows ~x10 per 2-3 min early, so spacing tiers needs costs ~x1e4+ apart. Still needs real playtesting, esp. with Essence multipliers.

## Placeholders / not built
- Community Haunting Meter, "ghosts summoned worldwide", the Weekly Rent Race rivals and rival houses are simulated (no server). `CONST.SHARE_URL` is a placeholder.
- Friend houses use copy/paste codes (`HLH1:`), no live visiting or real leaderboard.
- Notifications use the browser Notification API and only fire while the tab/app is open in the background (no service worker or push).
- Not built: Simulator stages past 7, franchise-specific stories, and a real server link between modes (the live link is browser-tab only, via the `storage` event).
